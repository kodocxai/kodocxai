# P16 실행 노트 - 시드 4·5 평가의 프로토콜 특이사항 (2026-10-06, 실험세션)

보고서·회신에 반영할 정직한 기록. 시드 1~3과의 차이는 아래 3건이 전부다.

1. **학습은 무중단 단일 실행** - 저자 터미널에서 러너로 수행(시드 4: 20:33~21:20,
   시드 5: ~22:08). 설정·에폭·데이터는 run_train_3seeds.ps1과 동일 인자.
2. **평가는 백그라운드 중단-재개 반복으로 수행** - 두 가지 파생 효과:
   - random 귀속·레이아웃 지터의 난수가 재개 경계마다 재시드됨(시드 1~3은 세션당
     단일 스트림). 무작위 기준선·교란으로서의 통계적 유효성에는 영향 없음 -
     여전히 시드된 균등 추출이다. 단 완전 재현에는 중단 지점이 필요하므로
     바이트 단위 재현성은 약함(시드 1~3 대비 한정).
   - phi_seed4/5.jsonl에 초기 사이클 중복 기록 발생 가능 → **평가 종료 후
     (doc_id, field, method) 기준 마지막 레코드만 남기는 dedupe 후처리 필수**
     (값은 결정적 재계산이라 동일 - 중복 제거만의 문제).
3. **kodx_eval.py 이어하기 최적화 패치(10-06)** - 완료된 (문서,필드,기법)의 귀속
   재계산·phi 재기록을 건너뜀. 수치에 영향 없는 제어 흐름 변경(신규 계산 항목의
   수식·순서 불변). 시드 1~3 산출물 무접촉.

평가 명령(재현용):
    python kodx_eval.py --model runs\seed{4,5}\last --docs _pilot\docs.jsonl
      --images data\pilot_images224 --annotations _pilot\annotations_park.jsonl
      --out P16_시드추가\seed{N}_v2.jsonl --save-phi P16_시드추가\phi_seed{N}.jsonl
      --skip-naopc --seed {N}
